# CancerAware

An educational website exploring how artificial intelligence and machine
learning can be used to study breast cancer tumour classification.

> **Important:** CancerAware is an educational project, not a medical
> device. It does not diagnose cancer or replace advice from a qualified
> healthcare professional.

## About the Project

CancerAware introduces the idea of analysing breast cancer datasets and
exploring how machine-learning models may classify tumours as **benign**
or **malignant**. The project is being developed as a learning and
research project.

## Current Website Features

-   Dark, modern visual design
-   Responsive landing-page sections
-   Glassmorphism styling and ambient background effects
-   Cursor glitter animation
-   Basic JavaScript interaction

## Built With

-   HTML
-   CSS
-   JavaScript

## Run Locally

1.  Clone the repository:

    ``` bash
    git clone https://github.com/Shadedex/CancerAware.git
    ```

2.  Open the project folder:

    ``` bash
    cd CancerAware
    ```

3.  Open `index.html` in your browser, or open the folder in your code
    editor and use a local development server.

## Project Goals

-   Build and improve the website interface.
-   Learn how machine-learning models can work with breast cancer
    datasets.
-   Explain the role and limitations of AI in healthcare research.
-   Keep the project understandable for beginners.

## Disclaimer

This project is for learning and demonstration only. Any model developed
as part of it may make mistakes and must not be used to make medical
decisions. Diagnosis and treatment decisions should be made with
qualified healthcare professionals.
