ABOUT THE PROJECT

Turning Data Into Insights

CancerAware is a machine learning research project that explores how patterns in breast cancer datasets can help classify tumours as benign or malignant.

The project uses a dataset and a classification model to study the role of artificial intelligence in healthcare research.
